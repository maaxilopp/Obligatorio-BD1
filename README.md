# Obligatorio - Torneo Interfacultades de Fútbol 5

Sistema de gestión del Torneo Interfacultades de Fútbol 5 de la Universidad Católica del Uruguay.

Trabajo obligatorio de Base de Datos I – Segundo semestre 2026.

## Tecnologías
- **Base de datos:** MySQL 8
- **Backend:** Python + FastAPI (consultas SQL parametrizadas, sin ORM)
- **Frontend:** React + Vite
- **Despliegue:** Docker Compose

- ## ## Estructura del repositorio
| Carpeta | Contenido |
|---|---|
| `db/` | Scripts SQL: esquema, triggers, usuarios, datos de prueba y reportes |
| `backend/` | API en FastAPI |
| `frontend/` | Aplicación en React |
| `docs/` | Diagrama del modelo y bitácora |
